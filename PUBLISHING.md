# R3X Labs Publishing Standard

## Core content types
- Guides
- Tools
- Prompts
- Signal updates

## Article standard
Every published article should include:
- SEO title
- Meta description
- Canonical URL
- Clear H1
- Structured H2/H3 sections
- Internal links where relevant
- Practical examples
- FAQ when useful
- Image alt text
- Updated sitemap entry

## Editorial rule
R3X Labs publishes practical AI workflows, tools and implementation guidance. Avoid hype, generic listicles and unsupported claims.
